### Linux Activity Monitor
**Folder:** `Linux-Activity-Monitor-main`

A Linux-based activity monitoring tool written in Python.  
It collects and analyzes system and user activity such as:
- Processes
- Files
- Command history
- System resources usage

#### Requirements
- Linux OS
- Python 3

#### How to Run
```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python main.py
Note: This project is designed to run on Linux.
